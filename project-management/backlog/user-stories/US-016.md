# US-016 — Fonctionnement en iframe

> Epic : [EPIC-04](../epics/EPIC-04.md) · Persona : Claire · MoSCoW : **Must** · Points : **3** · Version : v1
> Dépendances : US-004, US-013

## Story

En tant que Claire, je veux utiliser le catalogue dans l'iframe de mon outil d'achat, afin de ne pas quitter mon outil.

## Valeur

Ariba ouvre le PunchOut en iframe par défaut (risque R2).

## Critères d'acceptation

```gherkin
Fonctionnalité: Fonctionnement en iframe

  Scénario: En-têtes en session PunchOut
    Étant donné l'acheteur "BigCorp Ariba" avec l'origine iframe "https://s1.ariba.com"
    Quand une page de la session PunchOut est servie
    Alors la réponse n'a pas d'en-tête X-Frame-Options
    Et elle a l'en-tête Content-Security-Policy "frame-ancestors 'self' https://s1.ariba.com"

  Scénario: Hors session
    Quand une page boutique normale est servie
    Alors l'en-tête X-Frame-Options "sameorigin" est conservé

  Scénario: Documentation
    Alors la documentation décrit la configuration cookie de session (SameSite=None; Secure) et HTTPS
```
