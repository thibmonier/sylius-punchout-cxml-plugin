# US-015 — Bloquer le checkout pendant la session

> Epic : [EPIC-04](../epics/EPIC-04.md) · Persona : Claire · MoSCoW : **Must** · Points : **3** · Version : v1
> Dépendances : US-013

## Story

En tant que marchand, je veux qu'aucune commande Sylius ne puisse être passée depuis un panier PunchOut, afin d'éviter les doubles commandes hors circuit d'approbation.

## Valeur

Le PunchOut renvoie une réquisition, pas une commande.

## Critères d'acceptation

```gherkin
Fonctionnalité: Bloquer le checkout pendant la session

  Scénario: Accès direct au checkout
    Étant donné une session PunchOut active
    Quand j'ouvre "/en_US/checkout/address"
    Alors je suis redirigée vers mon panier
    Et un message indique d'utiliser "Transférer vers mon outil d'achat"

  Scénario: Complétion impossible
    Étant donné un panier PunchOut
    Quand une complétion de commande est tentée par un autre chemin
    Alors elle est refusée
```

## Notes

Listener kernel.request (priorité 1-7) + guard workflow complete (+ variante Doctrine winzou). Pas de guard sur address (boucle).
