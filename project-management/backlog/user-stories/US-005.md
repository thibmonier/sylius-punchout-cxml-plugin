# US-005 — Classification UNSPSC et unités

> Epic : [EPIC-01](../epics/EPIC-01.md) · Persona : Sophie · MoSCoW : **Must** · Points : **5** · Version : v1
> Dépendances : US-001

## Story

En tant que Sophie, je veux associer des codes UNSPSC et des unités aux produits, afin que les lignes renvoyées respectent les exigences des outils d'achat.

## Valeur

Classification et unité sont obligatoires dans chaque ItemIn cXML et attendues en OCI.

## Critères d'acceptation

```gherkin
Fonctionnalité: Classification UNSPSC et unités

  Scénario: Code UNSPSC hérité du taxon
    Étant donné le taxon "Chaises" associé au code UNSPSC "56101504"
    Quand un produit de ce taxon est renvoyé
    Alors sa ligne porte Classification domain="UNSPSC" "56101504"

  Scénario: Surcharge par produit
    Étant donné le produit "Chaise X" avec le code UNSPSC "56101501"
    Quand il est renvoyé
    Alors sa ligne porte le code "56101501"

  Scénario: Valeurs par défaut
    Étant donné un produit sans code ni unité
    Quand il est renvoyé à l'acheteur "BigCorp Ariba" (unité par défaut "EA", UNSPSC par défaut "44120000")
    Alors sa ligne porte UnitOfMeasure "EA" et le code "44120000"
```

## Notes

Unité OCI : table UN/ECE ↔ SAP T006 au choix de l'acheteur. Interface ItemClassificationResolverInterface taguée.
