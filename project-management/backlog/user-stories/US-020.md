# US-020 — Renvoyer le panier en OCI

> Epic : [EPIC-05](../epics/EPIC-05.md) · Persona : Claire · MoSCoW : **Must** · Points : **5** · Version : v1
> Dépendances : US-012, US-005

## Story

En tant que Claire sur SAP, je veux renvoyer mon panier dans SAP, afin de créer mon panier d'achat SAP.

## Valeur

Retour OCI (arbitrage : OCI en v1).

## Critères d'acceptation

```gherkin
Fonctionnalité: Renvoyer le panier en OCI

  Scénario: Retour OCI
    Étant donné une session OCI avec HOOK_URL "https://sap.bigcorp.example/hook"
    Et un panier avec 2 "Chaise X"
    Quand je clique sur "Transférer vers mon outil d'achat"
    Alors un formulaire est soumis vers HOOK_URL avec NEW_ITEM-DESCRIPTION[1], NEW_ITEM-QUANTITY[1]="2", NEW_ITEM-UNIT[1], NEW_ITEM-PRICE[1], NEW_ITEM-CURRENCY[1]="EUR", NEW_ITEM-VENDORMAT[1]
    Et le formulaire cible returntarget (défaut "_top")
    Et ~OkCode est renvoyé s'il a été reçu
    Et les décimales utilisent un point

  Scénario: Descriptions longues
    Quand la description dépasse la longueur maximale OCI
    Alors elle est tronquée proprement et la version complète part dans NEW_ITEM-LONGTEXT_1:132[1]
```

## Notes

Longueurs confirmées dans OCI 5.0 (`analysis/F-oci-field-reference.md`) : DESCRIPTION 40, UNIT 3, VENDORMAT 40, EXT_PRODUCT_ID 40.
