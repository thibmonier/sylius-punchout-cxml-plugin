# US-003 — Identifiants OCI

> Epic : [EPIC-01](../epics/EPIC-01.md) · Persona : Sophie · MoSCoW : **Must** · Points : **3** · Version : v1
> Dépendances : US-001

## Story

En tant que Sophie, je veux définir les identifiants OCI d'un acheteur SAP, afin d'authentifier les ouvertures de catalogue OCI.

## Valeur

OCI n'a pas d'enveloppe signée : l'authentification repose sur ces identifiants.

## Critères d'acceptation

```gherkin
Fonctionnalité: Identifiants OCI

  Scénario: Identifiants générés
    Quand je génère les identifiants OCI de l'acheteur "BigCorp SAP"
    Alors un identifiant et un mot de passe sont affichés une seule fois
    Et seule l'empreinte du mot de passe est enregistrée

  Scénario: Mauvais identifiants
    Quand SAP ouvre le catalogue avec un mot de passe erroné
    Alors aucune session n'est ouverte
    Et une page d'erreur générique est affichée
```
