# US-006 — Rattachement à une entreprise (company-accounts)

> Epic : [EPIC-01](../epics/EPIC-01.md) · Persona : Sophie · MoSCoW : **Could** · Points : **3** · Version : v1
> Dépendances : US-001

## Story

En tant que Sophie, je veux rattacher un acheteur à une entreprise company-accounts, afin que les sessions s'appliquent au compte de l'entreprise.

## Valeur

Synergie avec le plugin company-accounts (prix et groupes de l'entreprise).

## Critères d'acceptation

```gherkin
Fonctionnalité: Rattachement à une entreprise (company-accounts)

  Scénario: Plugin présent
    Étant donné que le plugin company-accounts est installé
    Quand je rattache l'acheteur à l'entreprise "BigCorp"
    Alors seul un client membre actif de "BigCorp" peut être choisi comme client rattaché

  Scénario: Plugin absent
    Étant donné que le plugin company-accounts n'est pas installé
    Alors le champ entreprise n'apparaît pas
    Et le plugin fonctionne normalement
```

Chargement conditionnel selon kernel.bundles.
