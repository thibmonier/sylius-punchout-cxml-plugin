# US-030 — Recevoir un OrderRequest

> Epic : [EPIC-08](../epics/EPIC-08.md) · Persona : Outil d'achat · MoSCoW : **Must** · Points : **8** · Version : v1.1
> Dépendances : US-018

## Story

En tant qu'outil d'achat, je veux envoyer le bon de commande approuvé, afin qu'il devienne une commande Sylius.

## Valeur

Ferme la boucle achat → commande.

## Critères d'acceptation

```gherkin
Fonctionnalité: Recevoir un OrderRequest

  Scénario: Commande créée
    Étant donné une réquisition issue d'un transfert PunchOut
    Quand l'outil d'achat poste un OrderRequest authentifié avec orderID "PO-1001"
    Alors une commande Sylius est créée avec les articles, les adresses BillTo et ShipTo et la référence "PO-1001"
    Et la réponse a le statut "200"

  Scénario: Doublon
    Quand le même OrderRequest est reposté
    Alors aucune nouvelle commande n'est créée
```

## Notes

Paiement sur compte ; synergies trade-credit / order-hold.
