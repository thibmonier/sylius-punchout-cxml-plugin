# US-004 — Domaines autorisés

> Epic : [EPIC-01](../epics/EPIC-01.md) · Persona : Sophie · MoSCoW : **Must** · Points : **3** · Version : v1
> Dépendances : US-001

## Story

En tant que Sophie, je veux déclarer les domaines autorisés pour le retour du panier et pour l'iframe, afin que le panier ne puisse partir que vers l'outil d'achat du client.

## Valeur

Empêche l'exfiltration du panier vers une URL arbitraire (risque R3).

## Critères d'acceptation

```gherkin
Fonctionnalité: Domaines autorisés

  Scénario: URL de retour autorisée
    Étant donné l'acheteur "BigCorp Ariba" avec le domaine autorisé "*.ariba.com"
    Quand un setup indique BrowserFormPost "https://s1.ariba.com/punchout/return"
    Alors la session est ouverte

  Scénario: URL de retour refusée
    Quand un setup indique BrowserFormPost "https://attacker.example/collect"
    Alors la réponse a le statut "403"
    Et aucune session n'est ouverte

  Scénario: HTTP et IP privées refusées
    Quand un setup indique BrowserFormPost "http://10.0.0.5/return"
    Alors la réponse a le statut "403"
```

## Notes

Les origines frame-ancestors sont saisies sur le même écran (utilisées par US-016).
