# US-001 — Créer un acheteur PunchOut

> Epic : [EPIC-01](../epics/EPIC-01.md) · Persona : Sophie · MoSCoW : **Must** · Points : **5** · Version : v1
> Dépendances : aucune

## Story

En tant que Sophie, je veux créer un acheteur PunchOut rattaché à un client Sylius, afin de préparer l'accès d'un grand compte.

## Valeur

Sans acheteur configuré, aucun PunchOut n'est possible ; le rattachement au client garantit ses prix.

## Critères d'acceptation

```gherkin
Fonctionnalité: Créer un acheteur PunchOut

  Scénario: Création d'un acheteur cXML
    Étant donné que je suis connectée à l'admin
    Quand je crée l'acheteur "BigCorp Ariba" avec le protocole "cXML", le canal "FASHION_WEB" et le client "achats@bigcorp.example"
    Alors l'acheteur apparaît dans la liste des acheteurs PunchOut
    Et il est actif et rattaché à ce client

  Scénario: Le client rattaché est obligatoire
    Quand j'enregistre un acheteur sans client rattaché
    Alors le formulaire est refusé avec le message "Un client est obligatoire"
    Et aucun acheteur n'est créé

  Scénario: Un acheteur désactivé ne peut pas ouvrir de session
    Étant donné l'acheteur "BigCorp Ariba" désactivé
    Quand l'outil d'achat envoie un setup valide pour cet acheteur
    Alors la réponse a le statut "403"
```
