# US-013 — Démarrer la session boutique

> Epic : [EPIC-04](../epics/EPIC-04.md) · Persona : Claire · MoSCoW : **Must** · Points : **8** · Version : v1
> Dépendances : US-007

## Story

En tant que Claire, je veux arriver connectée à mon compte client dans un panier dédié, afin de commander à mes prix sans manipulation.

## Valeur

Cœur de l'expérience acheteuse.

## Critères d'acceptation

```gherkin
Fonctionnalité: Démarrer la session boutique

  Scénario: Démarrage
    Étant donné une URL de démarrage valide pour l'acheteur "BigCorp Ariba"
    Quand mon navigateur ouvre cette URL
    Alors je suis connectée au client "achats@bigcorp.example"
    Et je vois un panier PunchOut vide, distinct du panier habituel de ce client

  Scénario: URL à usage unique
    Étant donné une URL de démarrage déjà utilisée
    Quand mon navigateur l'ouvre à nouveau
    Alors une page "Session expirée, relancez depuis votre outil d'achat" est affichée

  Scénario: URL expirée
    Étant donné une URL de démarrage émise il y a plus de 5 minutes
    Quand mon navigateur l'ouvre
    Alors aucune session n'est ouverte

  Scénario: Compte désactivé ou non vérifié
    Étant donné que le compte du client rattaché est désactivé
    Quand mon navigateur ouvre une URL valide
    Alors je ne suis pas connectée
    Et une page d'erreur générique est affichée
```

## Notes

Contexte de panier dédié (priorité 0), setCustomer (createdByGuest = true), Security::login après contrôles manuels (pré-auth 2.3 permissif).
