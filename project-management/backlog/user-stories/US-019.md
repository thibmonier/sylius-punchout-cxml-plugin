# US-019 — Taxes et frais de port optionnels

> Epic : [EPIC-05](../epics/EPIC-05.md) · Persona : Sophie · MoSCoW : **Should** · Points : **3** · Version : v1
> Dépendances : US-018

## Story

En tant que Sophie, je veux choisir si les taxes et le port estimés accompagnent le panier renvoyé, afin de respecter les attentes de chaque acheteur.

## Valeur

Certains acheteurs veulent ces montants, d'autres les refusent.

## Critères d'acceptation

```gherkin
Fonctionnalité: Taxes et frais de port optionnels

  Scénario: Désactivé par défaut
    Quand le panier est renvoyé
    Alors le message ne contient ni Tax ni Shipping

  Scénario: Activé
    Étant donné l'option "inclure les taxes" activée pour l'acheteur
    Quand le panier est renvoyé
    Alors PunchOutOrderMessageHeader contient Tax avec le montant de taxe du panier
```
