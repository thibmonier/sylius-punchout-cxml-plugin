# US-010 — ProfileRequest

> Epic : [EPIC-02](../epics/EPIC-02.md) · Persona : Outil d'achat · MoSCoW : **Must** · Points : **2** · Version : v1
> Dépendances : US-007

## Story

En tant qu'outil d'achat, je veux interroger le profil du fournisseur, afin de connaître les transactions supportées.

## Valeur

Obligatoire pour tout serveur cXML 1.1 et plus.

## Critères d'acceptation

```gherkin
Fonctionnalité: ProfileRequest

  Scénario: Profil
    Quand l'outil d'achat poste un ProfileRequest authentifié
    Alors la réponse liste la transaction "PunchOutSetupRequest" avec son URL
    Et l'option operationAllowed vaut "create edit inspect"
```
