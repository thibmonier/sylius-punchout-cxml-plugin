# Architecture C4 et séquences

> Phase 3 (Conception) · 2026-10-14

## Niveau 1 — Contexte

```mermaid
flowchart LR
    Claire([Claire<br/>acheteuse]) -->|navigue| Proc[Outil d'achat<br/>Ariba · Coupa · SAP SRM/S4]
    Marc([Marc<br/>admin e-procurement]) -->|configure le fournisseur| Proc
    Proc -->|setup cXML serveur-à-serveur<br/>entrée OCI navigateur| Shop[Boutique Sylius<br/>+ plugin PunchOut]
    Claire -->|iframe / fenêtre| Shop
    Shop -->|retour panier par formulaire<br/>auto-soumis du navigateur| Proc
    Sophie([Sophie<br/>admin Sylius]) -->|acheteurs, journal| Shop
    Julien([Julien<br/>intégrateur]) -->|installe, diagnostique| Shop
```

Le retour du panier ne passe **jamais** par un appel serveur à serveur : c'est le navigateur de Claire qui poste le formulaire vers l'outil d'achat (cXML `BrowserFormPost`, OCI `HOOK_URL`).

## Séquence — PunchOut cXML create

```mermaid
sequenceDiagram
    autonumber
    participant P as Outil d'achat
    participant B as Navigateur de Claire
    participant E as /punchout/cxml
    participant S as /punchout/start/{token}
    participant Shop as Shop Sylius
    participant T as /punchout/transfer
    P->>E: POST PunchOutSetupRequest (From, Sender + SharedSecret, BuyerCookie, BrowserFormPost)
    E->>E: limite, parse sûr, auth, anti-rejeu, liste blanche
    E-->>P: PunchOutSetupResponse 200 (StartPage = /punchout/start/{token})
    P->>B: ouvre StartPage (iframe ou fenêtre)
    B->>S: GET (jeton à usage unique, TTL 5 min)
    S->>S: consomme le jeton, contrôles du compte, login, panier PunchOut
    S-->>B: 303 vers la boutique (sans X-Frame-Options, CSP frame-ancestors)
    B->>Shop: navigation, ajout au panier (checkout bloqué)
    B->>T: POST Transférer (CSRF)
    T-->>B: page auto-soumise (cXML-base64, target _top)
    B->>P: POST BrowserFormPost (PunchOutOrderMessage)
```

## Séquence — OCI

```mermaid
sequenceDiagram
    autonumber
    participant SAP as SAP SRM / S4
    participant B as Navigateur
    participant O as /punchout/oci/{buyerCode}
    participant Shop as Shop Sylius
    participant T as /punchout/transfer
    SAP->>B: lien catalogue (HOOK_URL, identifiants, returntarget)
    B->>O: GET ou POST
    O->>O: limite, auth, liste blanche HOOK_URL, login, panier PunchOut
    O-->>B: 303 vers la boutique
    B->>Shop: navigation, ajout au panier
    B->>T: POST Transférer (CSRF)
    T-->>B: page auto-soumise (NEW_ITEM-*[n], target returntarget ou _top)
    B->>SAP: POST HOOK_URL
```

## Séquence — edit

Setup avec `operation="edit"` et des `ItemOut` → session `pending` qui stocke les `ItemOut` → au démarrage, `CartRebuilder` reconstruit le panier (un seul `process()`, lignes indisponibles signalées) → même transfert qu'en create.
